# Morad's Persian–English Dictionary v1.3.0

This release adds a **native Apple Dictionary.app source** — the same 79,591-entry
Persian → English lexicon compiled into a macOS `.dictionary` bundle that shows up
in Dictionary.app and system-wide **Look Up**, alongside the existing Kindle and
browser editions.

## What is included

- **Native Apple Dictionary bundle (`Morad's Persian-English Dictionary.dictionary`)**:
  a compiled Dictionary Services source. Unzip into `~/Library/Dictionaries`, open
  Dictionary → Settings, tick **Morad's Persian-English Dictionary**, and every one
  of the 79,591 canonical headwords plus 837,624 indexed lookup forms (Arabic/Persian
  kaf & yeh variants, ZWNJ plurals, attached suffixes, ezafeh, possessives) is
  searchable in Dictionary.app and via right-click **Look Up** in any Mac app.
- **Kindle edition:** the same MOBI7 dictionary for USB sideloading (unchanged pipeline).
- **Browser edition:** the static PWA for macOS, Windows, Android, iPhone and iPad
  (unchanged pipeline).
- **Shared data:** the native bundle is built from the *same* web shards the browser
  edition uses, so all three editions index identical lookup terms.

## The native dictionary (macOS)

1. Download **`Morad's Persian-English Dictionary.dictionary.zip`** and `SHA256SUMS.txt`
   from this release.
2. Optionally verify: `shasum -a 256 -c SHA256SUMS.txt`.
3. Double-click the ZIP to extract **`Morad's Persian-English Dictionary.dictionary`**
   (a macOS bundle — Finder shows it as one icon).
4. In Finder press **Cmd+Shift+G**, type `~/Library/Dictionaries`, and move the bundle in.
5. Quit and reopen **Dictionary**; open **Settings**, tick **Morad's Persian-English
   Dictionary**, and drag it up if you want it first.
6. Select a Persian word anywhere and choose **Look Up**, or search in Dictionary directly.

The compiler is Apple's Dictionary Development Kit (downloaded at build time from a
third-party mirror of Xcode's DDK; see the README security note). Both Intel and
Apple Silicon Macs are supported at the data level; the builder may need Rosetta on
Apple Silicon.

## Verification

- Python regression suite passes.
- Native XML validated with `xmllint` and the plist with `plutil`.
- DDK compiles the bundle and validates `Body.data`, `KeyText.index` and `EntryID.index`.
- Release ZIP checksum verified by the workflow before publishing.

## Important limitations

- The bundle is a third-party Dictionary Services source, not an Apple dictionary.
  No claims of testing on every macOS release.
- Some generated inflected forms may be linguistically unusual; they are index aliases,
  not separate sourced definitions.
- Editorial entries are not independently lexicographically reviewed.

This is a community dictionary project, not an Amazon or Apple product.
