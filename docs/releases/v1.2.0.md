# Morad's Persian–English Dictionary v1.2.0

This release turns the existing Kindle dictionary into a combined Kindle and cross-platform lookup project. It refreshes the lexical source snapshot, adds a static browser application for desktop and mobile, and rebuilds the Kindle dictionary from the same pinned data.

## What is included

- **Kindle edition:** a rebuilt MOBI7 Persian → English dictionary for USB sideloading.
- **Browser edition:** a static Progressive Web App (PWA) for macOS, Windows, Android, iPhone and iPad browsers.
- **Offline lookup:** the browser app can download the complete index and definition shards to local browser storage. No lookup API, account, subscription, or always-on dictionary server is required.
- **Normalization:** Arabic/Persian kaf and yeh variants, combining marks, ZWNJ, ezafeh forms, and common attached forms are handled by the shared lexicon pipeline.
- **Register and usage:** where source data supplies them, labels such as *archaic*, *rare*, *literary*, *figurative*, *colloquial*, *slang*, *impolite* and *vulgar* are retained rather than flattened into generic glosses.
- **Editorial additions:** 66 original candidate entries add Iranian idioms, conversational expressions and slang. They are visibly labelled **Editorial** so readers can distinguish them from dictionary sources. These entries have not yet undergone a full independent lexicographic review and should be treated as useful editorial suggestions, not definitive authority.

The browser build produced by the verified November 16, 2026 export contains **79,591 canonical entries and 837,624 searchable forms**. The release's `stats.json` and `web-manifest.json` files record the exact statistics for the Kindle and browser builds separately.

## Platform installation

### macOS

The browser edition works in current Safari, Chrome and other modern browsers. On **macOS Sonoma 14 or later**, open the site in Safari and choose **File → Add to Dock**. This creates a standalone web app in the Dock and Applications folder. In Chrome, use the install icon in the address bar or the browser menu's **Install app** command.

On older macOS versions, use the site in a normal browser tab; Chrome may still offer app installation. Once the app is open and online, press **Save for offline use** and wait for the completion message before going offline.

This is a PWA, not a native entry in Apple's Dictionary.app. It does not currently provide system-wide lookup when selecting a word in another Mac application.

### Windows

Open the published site in Chrome or Edge and choose **Install** from the address bar or browser menu. The app opens in its own window and can be pinned to Start or the taskbar. Press **Save for offline use** once while connected.

### Android

Open the site in Chrome and choose **Install app** or **Add to Home screen**. The installed PWA supports Android's text share target in browsers that implement the Web Share Target API: select text in another app, share it, and choose Morad's Dictionary. Press **Save for offline use** to cache the complete lexicon.

### iPhone and iPad

Open the site in Safari and choose **Share → Add to Home Screen**. Launch it from the saved icon. Search works within the app. iOS does not provide the same incoming PWA share-target behavior as Android in this release.

### Kindle

Download `Morads-Persian-English-Dictionary.mobi`, connect the Kindle by USB, and copy the file into the device's `documents` folder. Eject the device and select the dictionary manually in the language/dictionary settings or from a word-lookup panel. Do not use Send to Kindle: Amazon's conversion can strip the MOBI dictionary index.

## Verification and reproducibility

The release workflow:

1. downloads the pinned source snapshots and checks their exact byte sizes and SHA-256 hashes;
2. runs the Python regression suite;
3. downloads the upstream `kindling-cli` v0.46.2 Linux binary and verifies its SHA-256;
4. builds and validates the Kindle MOBI;
5. runs the required Kindle lookup suite against the resulting MOBI;
6. exports the browser PWA from the same lexical snapshots;
7. publishes the MOBI, browser ZIP, source lockfile, build statistics, manifest and SHA-256 checksums as release assets.

The release includes `SHA256SUMS.txt` so downloaded files can be checked independently.

## Important limitations

- The browser edition is an installable web app, not a native macOS, Windows or Android system dictionary service.
- A live browser URL requires GitHub Pages to be enabled for the repository. If it is not enabled, the workflow still builds the site and uploads it as a GitHub Actions artifact; the deployment step is skipped.
- Offline browser storage can be cleared by browser settings or the operating system. Use **Save for offline use** again if necessary.
- The 66 Editorial entries are not independently lexicographically reviewed. Source-labelled Wiktionary, HMT and Dehkhoda material remains distinguishable.
- Definitions from different sources can disagree or cover different senses. Source labels are retained to make that visible.
- There is no pronunciation audio, automatic Kindle update mechanism, or Send to Kindle compatibility.

This is a community dictionary project, not an Amazon or Apple product.
